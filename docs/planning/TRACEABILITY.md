## 1. Purpose

This matrix answers the question *"How do we know this requirement is met?"* by linking each requirement
to its specification, its delivery phase, its planned primary test, and the evidence that will prove it:

```text
Requirement (PRD) → Specification → Phase → Planned test → Evidence run (RUN-NNNN) → Phase acceptance
```

## 2. Rules

- The primary test of `REQ-<AREA>-NNN` is `TEST-<AREA>-NNN`. Additional tests (numbers 101 and up) are listed in
  the test documents and may also cover a requirement.
- **Evidence** stays `Not run` until a real execution is recorded under [evidence](../quality/evidence/README.md).
  Never link to a run that does not exist.
- **Validation** uses Not run / Passed / Failed / Inconclusive ([DOCUMENTATION_RULES](../DOCUMENTATION_RULES.md) §5).
- A requirement is met only when its validation is Passed with evidence and the phase gate has been accepted by the
  project owner ([ROADMAP](../../ROADMAP.md) §6).
- Update 2026-10-19: the validation column now records agent-run evidence (RUN-0001 to RUN-0004, unit tests). "Passed" here means verified by the agent; owner acceptance of the phase gates is still pending.
